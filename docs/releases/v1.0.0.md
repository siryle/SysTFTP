SysTFTP 是面向 macOS 的原生网络工具，集成 TFTP 服务器、TFTP 客户端、FTP 服务器和 Syslog 日志服务器。

- 简体中文界面、菜单、状态提示与本地日志。
- 优化中文表单、侧边栏、日志表格和不同窗口尺寸下的排布。
- 参考 IINA 风格的 DMG 安装窗口，提供中文拖拽提示和 Retina 高清背景。
- 支持 Apple Silicon 与 Intel，最低系统要求为 macOS 13。

安装：下载 `SysTFTP-macOS-1.0.0.dmg`，打开后将 SysTFTP 拖入右侧「应用程序」文件夹。

附件中的 `.sha256` 文件可用于验证下载完整性：

```bash
shasum -a 256 -c SysTFTP-macOS-1.0.0.dmg.sha256
```
